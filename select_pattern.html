SELECT PATTERN

この雰囲気を、どう作るか。

G-SELECTでは、色・形・素材の組み合わせを整理し、美しく納まりやすい空間づくりを提案します。

Color Pattern

GRAY × BROWN

建物と同系のグレーを軸に、ブラウンのアクセントで空間に奥行きと統一感を生む組み合わせ。 →
Layout Pattern

DIAMOND × FRAME

45°のダイヤモンドレイアウトで上質なリズムを演出。FRAMEのアクセントが空間を引き締める。 →
Material Pattern

STONE × WOOD

自然石の風合いとウッドの温もりを組み合わせ、空間に深みと自然な豊かさを生み出す素材構成。 →
Color Pattern

WHITE × GREEN

白を基調に植栽のグリーンをカラーアクセントとして取り込む、軽やかで明るい空間構成。 →
