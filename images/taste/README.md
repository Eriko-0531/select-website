# TASTE STYLE 施工事例写真の入れ方

各カテゴリのフォルダに、そのカテゴリの施工事例写真を入れてください。

## フォルダ一覧（10種）

**DAILY STYLE（15枚 = 5列×3段）**

| フォルダ名 | カテゴリ |
|---|---|
| cool | COOL |
| natural_cool | NATURAL COOL |
| natural_warm | NATURAL WARM |
| cute | CUTE |

**UNIQUE STYLE（10枚 = 5列×2段）**

| フォルダ名 | カテゴリ |
|---|---|
| hotel | HOTEL LIKE |
| resort | RESORT |
| botanical | BOTANICAL |
| vintage | VINTAGE |
| japandi | JAPANDI |
| japanese | JAPANESE |

## ファイルの置き方

- ファイル名は連番: DAILY STYLEは `01.jpg`〜`15.jpg`、UNIQUE STYLEは `01.jpg`〜`10.jpg`
- **`01.jpg` が一覧ページのサムネイル画像として使われます**。代表として一番良い写真を `01` にしてください。
- 写真はスマホ撮って出しのままでも構いません（サイズ調整・圧縮はこちら側で行います）。
