# STORY STYLE 施工事例写真の入れ方

各カテゴリのフォルダに、そのカテゴリの施工事例写真を入れてください。

## フォルダ一覧（8種）

| フォルダ名 | カテゴリ |
|---|---|
| relax | RELAX |
| green | GREEN |
| frame | FRAME |
| night | NIGHT |
| cafe | CAFE |
| gather | GATHER |
| hobby | HOBBY |
| play_wellness | PLAY & WELLNESS |

## ファイルの置き方

- ファイル名は連番: `01.jpg` 〜 `12.jpg`（4列×3段で表示するため **12枚** ）
- **`01.jpg` が一覧ページのサムネイル画像として使われます**。代表として一番良い写真を `01` にしてください。
- 写真はスマホ撮って出しのままでも構いません（サイズ調整・圧縮はこちら側で行います）。
